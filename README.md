Инструкция по установке HDMI AutoStart с логотипом на телевизоры Salute TV
Назначение: автоматическое переключение телевизора на HDMI 3 при включении с пульта с предварительным отображением заставки «Ночные Волки — Пятнашка».
Оборудование: телевизоры Hartens / Salute TV с Android 11 и контроллером MediaTek, компьютер Windows 10.
1. Принцип работы
После включения телевизора запускается приложение HDMI AutoStart, которое показывает полноэкранную заставку с логотипом в течение 6 секунд, затем переключает телевизор на HDMI 3.
Заставка появляется при запуске приложения, а не вместо заводского логотипа телевизора. Автоматический запуск зависит от назначения приложения домашним экраном и поведения прошивки телевизора при включении.
2. Необходимое программное обеспечение
•	ADB для Windows, установленный в C:\adb.
•	Приложение app-debug.apk.
•	Телевизор с включённой отладкой ADB.
•	Подключение компьютера и телевизора к одной локальной сети.
Исходный проект: HDMI-AutoStart на GitHub.
Готовые сборки: GitHub Actions.
3. Скачивание APK
Открой GitHub Actions, выбери последнюю успешную сборку Build Android APK с зелёной галочкой и скачай архив HDMI-AutoStart-APK из раздела Artifacts.
Распакуй архив и помести app-debug.apk в папку C:\adb.
4. Подключение телевизора
Открой командную строку Windows:
cd C:\adb
adb connect IP_ТЕЛЕВИЗОРА:5555
adb devices
Вместо IP_ТЕЛЕВИЗОРА укажи действительный адрес телевизора.
Если подключено несколько устройств, отключи ненужные соединения через adb disconnect или используй параметр adb -s IP:5555 для выбора конкретного телевизора.
5. Удаление старой версии
При обновлении может возникнуть ошибка:
INSTALL_FAILED_UPDATE_INCOMPATIBLE
Это означает, что цифровые подписи старого и нового APK не совпадают.
Сначала верни штатный домашний экран:
adb shell cmd package set-home-activity ru.sberdevices.starlauncher/.ui.mainscreen.MainActivity
Затем удали старую версию:
adb uninstall ru.hartens.hdmiautostart
Ожидаемый ответ — Success.
Удаление приложения сбрасывает его настройки, но не удаляет штатную оболочку Salute TV.
6. Установка новой версии
Выполни:
adb install C:\adb\app-debug.apk
При успешной установке появится:
Performing Streamed Install
Success
7. Проверка заставки
Принудительно запусти приложение:
adb shell am force-stop ru.hartens.hdmiautostart
adb shell am start -n ru.hartens.hdmiautostart/.MainActivity
Ожидаемая последовательность:
0–6 секунд
Полноэкранная заставка с логотипом и индикатором запуска
После 6 секунд
Автоматический переход на HDMI 3
8. Настройка автоматического запуска
После того как заставка и переключение на HDMI 3 успешно проверены, назначь приложение домашним экраном:
adb shell cmd package set-home-activity ru.hartens.hdmiautostart/.MainActivity
Проверь действие кнопки HOME:
adb shell input keyevent 3
Затем выключи телевизор пультом и включи повторно. Проверь, запускается ли заставка и происходит ли переключение на HDMI 3.
Для восстановления штатного домашнего экрана:
adb shell cmd package set-home-activity ru.sberdevices.starlauncher/.ui.mainscreen.MainActivity
9. Проверка HDMI-входов
На проверенных телевизорах установлено соответствие:
HDMI	MediaTek ID
HDMI 1	HW4
HDMI 2	HW5
HDMI 3	HW6
Для ручного переключения на HDMI 3:
adb shell am start -a android.intent.action.VIEW -d "content://android.media.tv/passthrough/com.mediatek.tvinput%2F.hdmi.HDMIInputService%2FHW6"
10. Диагностика
Проблема	Действие
device offline	Переподключить ADB и проверить разрешение отладки
more than one device	Выбрать устройство через adb -s IP:5555
INSTALL_FAILED_UPDATE_INCOMPATIBLE	Удалить прежнюю версию после восстановления штатного HOME
Появляется старый синий экран	Проверить, что установлен APK последней сборки
Логотип появляется, HDMI не открывается	Проверить ручную команду переключения
После включения нет заставки	Проверить назначение HOME и поведение прошивки
Итог: проект подготовлен для автоматического перехода на HDMI 3 с заставкой. Успешная сборка GitHub подтверждена, но работу новой версии на телевизоре необходимо окончательно проверить после переустановки APK.
